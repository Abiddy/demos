# Alpha Structural

Slash-style marketing site for [Alpha Structural](https://www.alphastructural.com/) — foundation repair and structural engineering in Los Angeles.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Slash-inspired dark design system (obsidian canvas, Playfair Display + Inter, copper accents)
